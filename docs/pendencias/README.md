# docs/pendencias — Backlog Verificado

Este diretório registra cada pendência de produto/auditoria com **estado verificado** (código + banco canônico),
para não re-trabalhar item já incorporado e nem perder trabalho parcial de agentes.

## Uso

1. Antes de tocar um item, leia `_ordem.md` (o arquivo que aponta o próximo item executável por impacto).
2. Toda correção nova: marca item como `FEITO` + PR linkada.
3. Item que outra auditoria disse "pendente" mas o código/banco prova como ok → `OK` com evidência.

## Arquivos

- `_ordem.md` — estado consolidado + ordem de execução.
